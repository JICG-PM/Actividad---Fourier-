# Actividad Formativa 2: Simulación y Análisis de Señales con la Transformada de Fourier

## Propósito del Código
Este repositorio contiene un script en Python (compatible con Google Colab) desarrollado para la asignatura de Señales y Sistemas. El objetivo es simular señales elementales (función escalón, pulso rectangular y senoidal) y aplicarles la Transformada Rápida de Fourier (FFT) mediante la librería scipy.fft.

## Características del Script
1.  *Generación de señales:* Crea las señales en el dominio del tiempo.
2.  *Cálculo de la FFT:* Obtiene el espectro de frecuencia de cada señal.
3.  *Visualización:* Grafica comparativamente el dominio del tiempo y el dominio de la frecuencia (magnitud).
4.  *Verificación de propiedades:* Demuestra numéricamente la propiedad de linealidad, el efecto del desplazamiento en el tiempo (la magnitud no cambia) y el escalamiento en frecuencia (dualidad tiempo-frecuencia).

## Herramientas Utilizadas
*   Python 3
*   NumPy (Cálculo numérico)
*   SciPy (Transformada de Fourier)
*   Matplotlib (Visualización gráfica)

## Cómo ejecutarlo
El código fue desarrollado en un entorno de Jupyter Notebook (Google Colab). Para ejecutarlo, simplemente copia el contenido del archivo .py o .ipynb en una celda de Colab y ejecútala.
